# v4.1.0：多账号管理

## 本次重点

**Google 账号档案 + 一键切换（已双账号实机验证）。**

## 多账号切换

EasyAG 现在可以把当前登录的 Antigravity 账号保存为本地档案（DPAPI 加密存储，凭据本体不落明文），并在多个账号之间一键切换：

- **保存当前账号**：把 Windows 凭据管理器中的 Antigravity 登录凭证（`gemini:antigravity`）连同账号指针一起留存。refresh_token 长期有效，随时可切回。
- **切换**：自动结束 Antigravity 进程（含后台语言服务，避免运行中的 daemon 把旧 token 写回）→ 写入目标账号凭证 → 自动重新启动。对话历史保留在本地，不受影响。
- **添加账号**：面板引导你在 Antigravity 里登录另一个 Google 账号，登录完成后一键收编为第二个档案。
- **导入 / 导出**：账号档案可导出为 JSON 跨机迁移。导出文件包含登录凭证（明文），请自行妥善保管。
- **删除**：仅删除本地档案，不影响当前登录。

档案的明文头（邮箱、时间戳）与加密体（DPAPI，当前用户作用域）分离存储：列表读取不触发解密，token 加密落盘。

## 实现与验证说明

- 凭证写入前使用与"清理并重新启动"相同的进程终止校验（可执行文件 + 用户 + 创建时间三重验证），切换失败不会破坏现有登录。
- 凭证 blob 对 EasyAG 内部只按不透明字节处理；日志与 API 响应不包含 token 内容。
- Windows 11 + Antigravity 桌面版 2.32.x 实机验证：凭证捕获、加密落盘、账号列表、双账号一键切换与切回全部通过。

## 兼容性

- 账号功能当前仅支持 Windows（凭据走 Windows 凭据管理器 + DPAPI）；macOS / Linux 显示为不支持并隐藏入口。
- 原有代理、汉化、上下文圆环行为不变；已按 fork 策略移除顶栏"检查更新"（不接入上游热更新）。
- 多账号轮换可能违反 Google 服务条款，风险自担；本工具仅操作本机凭证，不修改 Antigravity 程序本身。
